# podvorye-ryadom.ru

Сайт приложения «Подворье рядом» (ООО «ДС-Финанс»): страница приложения, справочник птицевода, политика конфиденциальности.

Статический сайт без сборки — файлы отдаются как есть. Страницы справочника собирает генератор
из базы приложения: `python3 tools/podvorye_site.py <эта папка> <папка со скриншотами>` в репозитории agronom-app.
Ручные правки в `spravochnik/` перезапишутся при следующей генерации.
